# Indonesia household energy study data

Data are organised by source:

| Folder | Contents |
| --- | --- |
| `partner_data/` | Household measurements, appliance inventory and processed demand profiles, with household labels replaced by anonymous IDs |
| `open_source_data/` | Public Indonesian residential profiles, 15-minute conversions and reference weather inputs |
| `survey_data/` | Aggregate CLASP/Ipsos survey inputs and the study's derived appliance parameters and timing templates |

Each folder documents its source, units and limitations. Survey-derived model inputs are not individual survey responses. Synthetic substitutes are labelled separately from measured data.

Data are being imported; the folder READMEs and checksums describe the completed upload.
